# BaTiO3 carrier-induced strain and polar-coordinate relaxation

This repository contains the public source-data package and auxiliary analysis scripts for the BaTiO3 carrier-induced strain study.

## Contents

- `batio3_carrier_strain_source_package_v1.zip`: source tables, occupation records, auxiliary stress records, relaxed structures, joint-relaxation traces, deformation-potential checks, and analysis scripts.
- The package supports the reported auxiliary SCAN, HSE06, PbTiO3, occupation, joint-relaxation, and deformation-potential checks.

## Scope and limitations

The package does not redistribute licensed PAW datasets, WAVECAR/CHGCAR files, or other restricted VASP payloads. The primary local-model source records and all manuscript figure-source tables are retained by the authors and can be released in a subsequent version when the public deposition is complete.

The scripts contain path settings that may need to be adjusted for the local checkout. See the package README and `tables/PROVENANCE.md` after extraction for provenance and protocol details.
